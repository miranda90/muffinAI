# `icon_block` — Icon Block (shortcode inline)

Shortcode **inline** para usar dentro de `content` (column, plain_text, visual). NO es un item del builder: no lleva `type`/`size`/`uid`.

## Campos
- **`icon`** (icon) — Icon
  - Valor: String
  - Default: `icon-lamp`
- **`align`** (switch) — Align
  - Valor: String
  - Opciones: `0` Default · `left` Left · `center` Center · `right` Right
- **`color`** (color) — Color
  - Valor: String
- **`size`** (text) — Icon size
  - Valor: String
  - Default: `25`

*Generado desde `class-mfn-builder-fields.php` (`get_inline_shortcode()`) — no editar a mano.*
