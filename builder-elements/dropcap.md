# `dropcap` — Dropcap (shortcode inline)

Shortcode **inline** para usar dentro de `content` (column, plain_text, visual). NO es un item del builder: no lleva `type`/`size`/`uid`.

## Campos
- **`background`** (color) — Background color
  - Valor: String
- **`color`** (color) — Text color
  - Valor: String
- **`circle`** (switch) — Style
  - Valor: String
  - Opciones: 
  - Default: `0`
- **`size`** (text) — Font size
  - Size in px or 1, 2, 3 for predefined sizes
  - Valor: String
  - Default: `1`
- **`font`** (font_select) — Font family
  - Valor: String
- **`content`** (textarea) — Dropcap letter, ie. A
  - Valor: String

*Generado desde `class-mfn-builder-fields.php` (`get_inline_shortcode()`) — no editar a mano.*
