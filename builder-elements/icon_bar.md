# `icon_bar` — Icon Bar (shortcode inline)

Shortcode **inline** para usar dentro de `content` (column, plain_text, visual). NO es un item del builder: no lleva `type`/`size`/`uid`.

## Campos
- **`icon`** (icon) — Icon
  - Valor: String
  - Default: `icon-lamp`
- **`link`** (text) — Link
  - Valor: String
- **`target`** (select) — Target
  - Valor: String
  - Opciones: `0` Default · `_blank` New tab or window
  - Default: `0`
- **`size`** (text) — Size
  - If you want large icon, then type large, leave field empty if you want default size
  - Valor: String
- **`social`** (select) — Social
  - Valor: String
  - Opciones: `""` No · `dribbble` Dribbble · `facebook` Facebook · `flickr` Flickr · `google` Google · `instagram` Instagram · `linkedin` LinkedIn · `pinterest` Pinterest · `twitter` Twitter · `vimeo` Vimeo · `youtube` Youtube

*Generado desde `class-mfn-builder-fields.php` (`get_inline_shortcode()`) — no editar a mano.*
