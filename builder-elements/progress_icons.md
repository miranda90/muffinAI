# `progress_icons` — Popup (shortcode inline)

Shortcode **inline** para usar dentro de `content` (column, plain_text, visual). NO es un item del builder: no lleva `type`/`size`/`uid`.

## Campos
- **`icon`** (icon) — Icon
  - Valor: String
  - Default: `icon-lamp`
- **`image`** (upload) — Image url
  - If you dont want to use icon you can enter image URL
  - Valor: String
- **`count`** (text) — Number of icons
  - Valor: String
  - Default: `5`
- **`active`** (text) — Number of active icons
  - Valor: String
  - Default: `3`
- **`background`** (color) — Color
  - Valor: String
- **`transparent`** (switch) — Transparent background
  - Valor: String
  - Opciones: 
  - Default: `0`

*Generado desde `class-mfn-builder-fields.php` (`get_inline_shortcode()`) — no editar a mano.*
