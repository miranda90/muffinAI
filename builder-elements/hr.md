# `hr` — Hr (shortcode inline)

Shortcode **inline** para usar dentro de `content` (column, plain_text, visual). NO es un item del builder: no lleva `type`/`size`/`uid`.

## Campos
- **`height`** (text) — Height
  - Valor: String
  - Default: `30`
- **`style`** (switch) — Line style
  - Valor: String
  - Opciones: `0` Default · `dots` Dots · `zigzag` ZigZag
  - Default: `0`
- **`line`** (switch) — Line width
  - for style: default
  - Valor: String
  - Opciones: `0` Default · `narrow` Narrow · `wide` Wide
  - Default: `0`
- **`color`** (color) — Line color
  - Valor: String
- **`themecolor`** (switch) — Theme color
  - Use the same color as theme color
  - Valor: String
  - Opciones: 
  - Default: `0`
